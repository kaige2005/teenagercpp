### 2.2 知识阶段内容 (60 XP)

#### 场景故事: 魔法学院的入门咒语 (约900字)

**【第1页 - 收到通知书】**

清晨的阳光穿透云层，照耀在一座悬浮于天空中的宏伟建筑上。金色的尖塔顶闪烁着神秘的光芒，彩虹般的魔法符文在半空中缓缓流动。

小极猛地从床上跳起来，手中紧攥着一张散发着淡淡银光的羊皮纸。

"是真的！是真的！"他兴奋地挥舞着那张纸，"我被录取了！C++魔法学院！"

身旁的小灵正坐在窗前，仔细研读着手中的通知书，眼中闪烁着期待的光芒。

"在这里，每一行代码都是一个魔法咒语，"小灵轻轻念着，"每一个程序都是一次奇妙的旅程..."

"那还等什么！"小极一把拉起小灵的手，"我们快去报到吧！"

**【第2页 - 抵达学院大门】**

穿过云层，两人终于来到了传说中的C++魔法学院大门前。

那是一扇由星光与代码构成的金色巨门，门上刻满了神秘的符号。当小极和小灵走近时，大门散发出柔和的光芒，仿佛在欢迎这两位年轻的学徒。

"听说每个程序员的第一句咒语，都是向世界问好。"小灵翻开入学手册，"这是我们成为正式魔法师的第一步。"

大门缓缓打开，一位须发皆白的守门老法师出现在他们面前。他的眼睛深邃如星空，法杖顶端的水晶散发着智慧的光芒。

"欢迎你们，年轻的学徒们。"老法师慈祥地微笑着，"我是这里的守门人。在正式开始学习之前，你们必须先学会程序员的第一个魔法咒语。"

**【第3页 - 魔法显现】**

老法师挥动手中的法杖，空中顿时浮现出发光的代码符文：

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, World!" << endl;
    return 0;
}
```

"这就是最基础的'问候咒'！"老法师解释道，"让我们一起破解它的秘密..."

小极睁大眼睛："这些符号是什么意思？看起来好神秘！"

"别担心，"老法师耐心地开始讲解，"每一行都有其特殊的含义。让我一一告诉你们..."

**【第4页 - 初识魔法公式】**

"第一行 `#include <iostream>` 是准备工具包，就像施展魔法前需要准备材料一样。"

"第二行 `using namespace std;` 表示我们使用标准魔法术语。"

"第三行 `int main()` 是程序的入口，魔法仪式从这里开始。"

"第四行 `cout` 是向世界说话的魔法喇叭，那些 '<<' 符号就像声音的传播方向。"

"最后一行 `return 0;` 表示魔法仪式顺利完成。"

小灵认真地做着笔记，小极则跃跃欲试："我明白了！现在可以让我试试吗？"

老法师微笑着点头："当然可以。但只有理解了原理，才能真正掌握魔法。先去完成知识测验吧！"

**【第5页 - 开始学习】**

"记住，"老法师语重心长地说，"编程就像魔法，需要细心和耐心。每一个符号都很重要，哪怕是一个小小的分号。"

小极和小灵相视一笑，眼中充满了对即将开始的魔法之旅的期待。

"那么，让我们开始吧！欢迎来到C++魔法学院！"
