}

/* 内容淡入 */
@keyframes contentFade {
  0% { opacity: 0; transform: translateY(10px); }
  100% { opacity: 1; transform: translateY(0); }

## 8. CodeCombat借鉴设计 (2026-04-08新增)

### 8.1 代码执行可视化 (高优先级)

**借鉴来源**: CodeCombat即时视觉反馈机制

**设计目标**: 让代码执行过程可见，增强"代码→结果"的连接感

#### 8.1.1 实践阶段 - 输出动画

```
代码编辑器区域:                        可视化执行区:
┌─────────────────────────┐           ┌─────────────────────────┐
│ cout << "Hello" << endl;│  ──────►  │  📺 执行预览          │
│ cout << "World" << endl;│           │  ─────────────────     │
│                         │           │                         │
│ [运行]                  │           │  ▶ Hello                │
│                         │           │    (打字机效果 50ms/字) │
│                         │           │  ▶ World                │
│                         │           │    (换行动画)           │
│                         │           │                         │
│                         │           │  ✓ 执行完成! 0.05s      │
└─────────────────────────┘           └─────────────────────────┘
```

**动画规格**:

| 元素 | 动画 | 时长 | 触发条件 |
|------|------|------|---------|
| 输出文字 | 打字机效果 | 50ms/字符 | 执行cout语句时 |
| 换行 | 光标下移+闪烁 | 200ms | 遇到endl时 |
| 数字 | 数字滚动 | 800ms | 输出数字时 |
| 完成标识 | ✓淡入 | 300ms | 程序return 0后 |

#### 8.1.2 执行过程可视化

```cpp
// 用户代码:
int main() {
    cout << "你好" << endl;
    cout << 42 << endl;
    return 0;
}

// 执行过程动画序列:
Step 1: [高亮] int main() {      [状态条] 进入主函数
        ↓ 500ms
Step 2: [高亮] cout << "你好"    [状态条] 准备输出字符串
        ↓ 300ms
Step 3: [预览区] 你...好...     [状态条] 输出中
        ↓ (50ms × 2字符)
Step 4: [预览区] 你好█          [状态条] 换行中 (闪烁)
        ↓ 200ms
Step 5: [高亮] cout << 42        [状态条] 准备输出数字
        ↓ 300ms
Step 6: [预览区] 你好
        42 (数字滚动 0→42)       [状态条] 输出中
        ↓ 800ms
Step 7: [高亮] return 0          [状态条] 程序结束
        ↓ 300ms
Step 8: [预览区] ✅ 程序执行成功!  [状态条] 完成
```

**UI布局调整**:
- 原布局: 左侧步骤 + 右侧代码(850px)
- 新布局: 左侧步骤(350px) + 中间代码(500px) + 右侧可视化(350px)
- 或折叠式: 点击"运行"后展开可视化面板
