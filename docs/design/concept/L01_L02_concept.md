## 执行摘要

本设计将L01「你好，C++！」和L02「分支魔法」从传统关卡格式重构为**三阶段课程格式**（知识+实践+挑战），统一融入**C++魔法学院**世界观，通过**小极、小灵**双主角的故事线提升学习体验。

### 关键决策

| 决策项 | 决策内容 | 理由 |
|--------|----------|------|
| 统一XP | 170→190 XP（与L03一致） | 学习价值对等 |
| 调整测验 | 3→4题 | 与L02/L03一致 |
| 调整填空 | 3→4空 | 知识密度均衡 |
| L01挑战XP | 20→30 | 三阶段统一 |
| 故事衔接 | L01入学→L02学习→L03探险 | 角色成长曲线 |

## 第一部分：架构设计 (Architect)

### 1.1 三阶段标准结构

```
Lesson
├── 基本信息 (id/title/prerequisite/totalXp)
└── phases[3]
    ├── Phase 1: Knowledge (知识)
    │   ├── scene (场景故事)
    │   ├── concept (概念卡片)
    │   ├── quiz (3-4道测验)
    │   └── fillblank (3-4道填空)
    │   └── totalXp: 60
    │
    ├── Phase 2: Practice (实践)
    │   ├── description (任务描述)
    │   ├── steps[] (编程步骤)
    │   ├── template (代码模板)
    │   ├── checkRules (检查规则)
    │   └── badge: master徽章
    │   └── rewardExp: 100
    │
    └── Phase 3: Challenge (挑战)
        ├── buggyCode (错误代码)
        ├── hints[] (提示列表)
        ├── expectedFix (预期修复)
        └── badge: bug_hunter徽章
        └── rewardExp: 30
```

## 第二部分：故事设计 (Storyteller)

### 2.1 世界观

**C++魔法学院**: 魔法与编程同源，代码即咒语

**学院地图**:
```
新手村(L1) → 智慧之门(L2) → 刷怪峡谷(L3) → ... → 云端之巅
```

### 2.2 角色

| 角色 | 性格 | 学习风格 | 在故事中的作用 |
|------|------|----------|----------------|
| **小极** | 热血、好奇、冒失 | 先动手后理解 | 错误示范，实践中学习 |
| **小灵** | 冷静、细心、善于观察 | 先理解后实践 | 正确引导，总结规律 |

### 2.3 L01 故事线

> **起**: 收到通知书 → 魔法学院大门 → 守门老法师传授"问候咒"
> **承**: 学习C++魔法公式 → 小极尝试修改
> **转**: 编写个性化问候程序
> **合**: 发现"语法小偷" → 抓Bug → 获得双徽章

**情感曲线**: 期待(5) → 专注(3) → 兴奋(4) → 高潮(5)

### 2.4 L02 故事线

> **起**: 正式入学第一堂课 → 智慧之门的猜数字谜题
> **承**: 魔法教授讲解分支魔法 → 小极猜50，门给提示
> **转**: 编写完整猜数字游戏 → 小极编写，小灵测试
> **合**: 小灵发现== vs =陷阱 → 顿悟 → 获得双徽章

**情感曲线**: 好奇(4) → 专注(3) → 兴奋(4) → 顿悟(5)

### 2.5 课程衔接

```
L01结局: 获得徽章，正式入学
   ↓ 承接
L02开场: "作为魔法学院的正式学员..."
   ↓ 承接
L02结局: 掌握分支魔法，通过智慧之门
   ↓ 预告
L03预告: "前方是刷怪峡谷，学习循环魔法..."
```
