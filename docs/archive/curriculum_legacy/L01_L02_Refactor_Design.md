#### 1.3.2 概念卡片

**标题**: C++程序的魔法公式

**内容**:
```
每个C++程序都有固定的"魔法公式"：

📦 第1步：准备工具包
#include <iostream>
→ 就像准备魔法材料，iostream是"输入输出工具包"

🎭 第2步：命名空间
using namespace std;
→ 选择使用"标准魔法术语"

🚪 第3步：程序入口
int main() { ... }
→ 程序从这里开始执行，就像魔法仪式的主舞台

📢 第4步：输出咒语
cout << "内容" << endl;
→ 向世界输出信息，endl表示"换行"

✅ 第5步：结束仪式
return 0;
→ 告诉电脑"程序顺利结束"
```

**关键要点**:
- `#include` 是"准备工具"的咒语
- `main()` 是程序的起点，电脑从这里开始执行
- `cout` 是输出用的"魔法喇叭"
- 每行代码结束要加 `;`（分号），就像每句话结束要加句号

#### 2.3.2 概念卡片

**标题**: 分支魔法的奥秘

**内容**:
```
🎯 基础 if 语句

if (条件) {
    // 条件成立时执行
}

示例：
if (guess == secret) {
    cout << "猜对了！" << endl;
}

---

🎭 if-else 语句

if (条件) {
    // 条件成立时执行
} else {
    // 条件不成立时执行
}

示例：
if (guess > secret) {
    cout << "太大了" << endl;
} else {
    cout << "太小了" << endl;
}

---

🎪 if-else if-else 链式判断

if (条件1) {
    // 处理情况1
} else if (条件2) {
    // 处理情况2
} else {
    // 其他情况
}

---

⚖️ 比较运算符

| 符号 | 含义 | 示例 |
|------|------|------|
| == | 等于 | a == b |
| != | 不等于 | a != b |
| > | 大于 | a > b |
| < | 小于 | a < b |
| >= | 大于等于 | a >= b |
| <= | 小于等于 | a <= b |
```

**关键要点**:
- `if` 检查条件，条件为真时执行代码块
- `==` 是比较相等（两个等号），`=` 是赋值（一个等号）
- `else` 处理"否则"的情况
- 比较运算符的结果是 true（真）或 false（假）

#### 2.3.3 知识测验 (3道)

**问题1**:
```

B. if (a == 5)

D. if (a equal 5)
答案：B
解释：比较相等要用两个等号==，一个等号=是赋值。

```


**问题3**:

```
选项：
A. if (guess < secret)
B. if (guess > secret)

D. if (guess == secret)
答案：B
解释：guess>secret表示猜测的数字比答案大，即"猜大了"。
```

### 2.5 挑战阶段 (30XP)

#### 2.5.1 Bug猎手

**标题**: 猜数字的逻辑陷阱

**描述**:
```
小灵写了一个猜数字程序，但里面藏着一个逻辑Bug。
这个Bug只在特殊情况下才会出现...

找出Bug并修复它！
```

**Buggy代码**:
```cpp
#include <iostream>
using namespace std;

int main() {
    int secret = 50;
    int guess;
    
    cout << "请猜一个数字：";
    cin >> guess;
    
    if (guess = secret) {  // ⚠️ Bug在这里！
        cout << "猜对了！" << endl;
    } else if (guess > secret) {
        cout << "太大了" << endl;
    } else {
        cout << "太小了" << endl;
    }
    
    return 0;
}
```

**Bug分析**:
- 第9行: `if (guess = secret)` 是赋值而非比较！
- 应该改为 `if (guess == secret)`
- 这个Bug会让条件永远为真（赋值表达式的值是50，非0即真）

**修复后**:
```cpp
if (guess == secret) {  // 两个等号才是比较
    cout << "猜对了！" << endl;
}
```

**解释**: `=` 是赋值，把右边的值给左边；`==` 是比较，判断两边是否相等。

**奖励**:
- **经验**: 30 XP
- **徽章**: `branch_bug_hunter` 🐛
