## 一、当前系统现状分析

```

├── UI层
│   ├── MainForm (课程地图)
│   ├── ModernLessonForm (三阶段课程容器) ✅ L03已使用
│   ├── KnowledgePhaseForm (知识阶段) ✅
│   ├── PracticePhaseForm (实践阶段) ✅

│   ├── templates/*.cpp (代码模板)

├── 用户数据层
│   └── SQLite (进度、XP、徽章)

**目标**: L01/L02迁移到新格式，统一8课世界观

```

│   ├── L01: 魔法学院入学
│   └── L02: 智慧之门猜数字
├── 概念卡片 (5张+4张)

**调用Skill**: `task-with-validation`
- 每项子任务带验证检查点
- 自动编译验证
- 运行时测试验证

#### 2.1.2 UI布局优化

**问题**: 当前布局偏右 + 分辨率适配不足

```
布局重构:
├── 主窗体居中算法优化
│   ├── 原: 固定位置
│   └── 新: 屏幕居中 + DPI缩放
├── 三阶段内容区
│   ├── 原: 850px (可能偏右)
│   └── 新: 850px (居中) / 850px + 350px可视化(新增)
├── 代码编辑器
│   ├── 原: 可能遮挡按钮
│   └── 新: Dock安全边距 60px
└── 响应式断点
    ├── 1280×720: 紧凑模式
    ├── 1366×768: 标准模式 (默认)
    └── 1920×1080: 宽屏模式
```

**调用Skill**: `frontend-design`
- 响应式布局设计
- 视觉一致性检查

### Skill调用策略

```
需求阶段:
  └── `pd-start` → 启动4-Phase产品设计

设计阶段:
  ├── `frontend-design` → UI/UX设计
  └── `pd-review` → 设计评审

开发阶段:
  ├── `tdd` → 测试驱动开发
  ├── `task-with-validation` → 带验证的任务
  └── `superpowers:subagent-driven-development` → 并行开发

发布阶段:
  ├── `precheck` → 预提交检查
  └── `release` → 标准化发布

运行时:
  └── `context-aware-assistant` → 场景感知助手
```
