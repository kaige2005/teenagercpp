## 🎯 主要更新

### L01/L02 三阶段课程重构 (重大更新)

将传统单阶段课程格式全面升级为**三阶段教学格式**，与L03保持一致。

#### 三阶段结构
1. **知识阶段** (60 XP)
   - 场景故事：沉浸式魔法学院世界观
   - 概念卡片：核心知识点可视化
   - 测验：4道选择题
   - 代码填空：4道填空题

2. **实践阶段** (100 XP)
   - 分步引导的编程任务
   - TODO标记的代码模板
   - 自动检查规则验证
   - Master徽章解锁

3. **挑战阶段** (30 XP)
   - Bug猎手游戏化挑战
   - 渐进式提示系统
   - Bug Hunter徽章解锁

## ✨ 课程详情

### L01《你好，C++！》
- **世界观场景**: 魔法学院入学 - 守门老法师传授问候咒
- **实践项目**: 个性化问候程序
- **Bug猎手**: 语法错误修复（分号、引号、箭头方向）
- **徽章**: 👋 hello_master + 🐛 hello_bug_hunter

### L02《分支魔法》
- **世界观场景**: 智慧之门猜数字谜题 - 魔法教授的试炼
- **实践项目**: 完整猜数字游戏
- **Bug猎手**: == vs = 逻辑陷阱（经典C++陷阱）
- **徽章**: 🔀 branch_master + 🐛 branch_bug_hunter

### L03《数组探险》
- **世界观场景**: 刷怪峡谷法术槽位
- **实践项目**: 法术强度计算
- **Bug猎手**: 数组边界错误
- **更新**: 测验3题 → 4题（与L01/L02统一）
- **徽章**: 📊 spells_master + 🐛 spells_hunter

## 🎮 游戏化设计亮点

### 统一世界观: C++魔法学院
- 8课连贯故事线（L01-L08）
- 两位主角贯穿始终：
  - **小极**: 热血冲动，从实践中学习
  - **小灵**: 冷静细心，先理解后实践

### 徽章体系
```
课程 → Master徽章 → Bug Hunter徽章 → 课程完成
 L01 → hello_master → hello_bug_hunter → L01_complete
 L02 → branch_master → branch_bug_hunter → L02_complete
 L03 → spells_master → spells_hunter → L03_complete
```

### XP解锁链
```
完成L01获得190XP → 解锁L02
完成L02获得190XP → 解锁L03 (总计380XP)
完成L03获得190XP → 完成前三章 (总计570XP)
```

### 数据格式升级
- 课程JSON: 传统格式 → 三阶段结构
