# 产品输入归档 (Product Inputs)

本目录归档 TeenC++ 立项与设计阶段的**原始输入材料**。

**来源**：原位于工作区 `claude-workspace/userfile/`。该目录从来不在 git 内，为避免清理本地工作区时丢失产品开发资料，于 2026-10-06 随项目终止归档移入本仓库。

| 文件 | 用途 |
|------|------|
| `关键提示交互.txt` | 项目**终极目标**的原始陈述：培养 12–16 岁青少年达成省级信息学奥赛参赛能力；并包含对产品改版方向的原始要求（知识学习与编程实践融合、知识部分计分、兼顾趣味性与青少年学习规律）。是全部课程设计的上游依据 |
| `大纲.md` | NOI 2025 竞赛大纲摘要：等级化（入门级 CSP-J / 提高级 NOIP・CSP-S / NOI 级）、难度系数、入门级知识点清单 |
| `NOI_Syllabus_Edition_2025.pdf` | 《全国青少年信息学奥林匹克系列竞赛大纲 2025 修订版》**官方全文**（25 MB）。课程知识点覆盖范围的权威依据 |
| `exported_image.png` | 上述竞赛大纲的**思维导图**（入门级 / 提高级 / NOI 级三层全展开） |
| `家庭版游戏化C++零基础学习全方案.md` | 产品方案：家庭场景定位、Dev-C++ 工具选型、游戏化激励体系、8 周课程实施方案 |

## 使用提示

- `关键提示交互.txt` 描述的目标是**省级信奥参赛能力**，而当前课程（L01–L03）仅覆盖入门级的最初部分——两者之间还有很大距离。将来若重启开发，这是判断"做到哪了、还差什么"的基准。
- `NOI_Syllabus_Edition_2025.pdf` 与 `exported_image.png` 是 CCF 公开发布的竞赛大纲，此处仅为设计参考留存；对外引用请注意原始版权。
