## ✨ TeenC++ v1.3.0 —— 最终归档版本

**TeenC++** 是专为 12-16 岁中国青少年设计的游戏化 C++ 编程学习平台。
v1.3.0 将第 1、2 课重构为与第 3 课一致的三阶段结构，并修复了 Beta 测试发现的三项 Bug猎手问题。

> ⚠️ 这是 TeenC++ 的**最终版本**，项目已于 2026-10 停止开发。

---

## 🎯 本次发布亮点

### 🎓 三课统一三阶段结构

L01《你好，C++！》与 L02《分支魔法》由传统关卡改为三阶段教学：

| 阶段 | 内容 |
|------|------|
| 🧠 **知识讲解** | 场景故事 + 概念卡片 + 测验 + 代码填空 |
| 💻 **编程实践** | 完整的动手编程任务 |
| 🐛 **Bug猎手** | 找出并修复代码中的隐藏 Bug |

### 🐛 Bug猎手修复

| 问题 | 修复方式 |
|------|----------|
| Bug 标记位置不准确 | 新增 `bugs[]` 数组，逐条标注行号与期望代码 |
| 缺少标准答案参考 | 新增 `referenceCode` 字段 |
| 答案校验空格敏感 | 新增 `validationMode: "normalized"` |

---

## 📚 包含课程

| 课程 | 主题 | 格式 |
|------|------|------|
| **L01** | 你好，C++！ | ⭐ 三阶段 |
| **L02** | 分支魔法 | ⭐ 三阶段 |
| **L03** | 数组探险 | ⭐ 三阶段 |

---

## 📥 快速开始

**系统要求**：Windows 10/11 (64位) · .NET Framework 4.8 · 可选 Dev-C++ 5.11

1. 下载 `TeenCppEdu-v1.3.0.tar.gz`
2. 解压到任意目录（如 `D:\TeenCppEdu`）
3. 双击运行 `TeenCppEdu.exe`

---

## ⚠️ 重要说明

- **二进制未变更**：`TeenCppEdu.exe` 与 v1.2.0 为同一份编译产物（无代码改动）；
  v1.3.0 的全部变更在课程数据与校验规则。
- **未经编译与运行时验证**：归档环境无 .NET 构建工具链，本版本由 v1.3.0-beta.2 测试包提升而来。
- **项目已终止**：2026-10 停止开发，不再提供后续更新或支持。
