**版本类型**: 正式版（最终版）

## 下载

- 主程序: `TeenCppEdu.exe`
- 完整包: `TeenCppEdu-v1.3.0.tar.gz`（含所有依赖与课程数据）

---

## 本次发布亮点

### 🎓 第1课、第2课三阶段重构

L01《你好，C++！》与 L02《分支魔法》从传统关卡改为与 L03 统一的**三阶段结构**：

| 阶段 | 内容 |
|------|------|
| 🧠 **知识讲解** | 场景故事 + 概念卡片 + 测验 + 代码填空 |
| 💻 **编程实践** | 完整的动手编程任务 |
| 🐛 **Bug猎手** | 找出并修复代码中的隐藏 Bug |

至此 L01 / L02 / L03 三课全部采用统一的三阶段格式与「魔法学院」主题。

### 🐛 Bug猎手修复

针对 Beta 测试反馈的三项问题：

| 问题 | 修复方式 |
|------|----------|
| Bug 标记位置不准确 | 新增 `bugs[]` 数组，逐条标注行号与期望代码 |
| 缺少标准答案参考 | 新增 `referenceCode` 字段 |
| 答案校验过于严格（空格敏感） | 新增 `validationMode: "normalized"`，空格差异不再判错 |

1. 解压 `TeenCppEdu-v1.3.0.tar.gz` 到任意目录

3. 完成第1课解锁第2课，依次推进

## 重要说明

- **二进制未变更**：本版本的 `TeenCppEdu.exe` 与 v1.2.0 为同一份编译产物（自 v1.2.0 起无代码改动）。v1.3.0 的全部变更集中在**课程数据与校验规则**。
- **项目已终止**：TeenC++ 于 2026-10 停止开发，v1.3.0 为最终归档版本，不再发布后续更新。
- **验证状态**：归档环境不具备 .NET 构建工具链（无 dotnet SDK / MSBuild / VS），因此本版本**未经编译与运行时验证**，仅由 v1.3.0-beta.2 的测试包提升而来。
