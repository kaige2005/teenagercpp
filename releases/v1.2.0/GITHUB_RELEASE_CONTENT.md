## 📥 快速开始

### 系统要求
- Windows 10/11 (64位)
- .NET Framework 4.8
- 可选: Dev-C++ 5.11 (用于代码练习)

### 安装步骤

**方法一：下载预编译版本 (推荐)**
1. 下载 `TeenCppEdu-v1.2.0.tar.gz`
2. 解压到任意目录（如 `D:\TeenCppEdu`）
3. 双击运行 `TeenCppEdu.exe`

**方法二：从源码构建**
```bash
git clone https://github.com/kaige2005/teenagercpp.git
cd teenagercpp/src
dotnet build TeenCppEdu/TeenCppEdu.csproj -c Release
```

### 首次使用
1. 完成 L01，获得 100 XP
2. 解锁 L02，学会分支语句
3. 解锁 L03，体验全新三阶段学习！
